# Modelgebaseerde verspaningsgids

Praktische gids voor draaien en frezen. Ontdek welke gegevens je nodig hebt voor elk verspaningsmodel en hoe je de uitkomst toetst met metingen op je eigen machine.

## De gids gebruiken

Open [index.html](index.html) vanuit een lokale kopie van deze repository in je browser. De gids bestaat uit statische HTML, CSS en JavaScript en vereist geen installatie of buildstap.

- Vertrek van een machinevraag. Reken [ruwheid bij draaien](ruwheid.html) of [energie per goed stuk](energie.html) door, of bekijk de praktijkproeven voor slijtage, doorbuiging, chatter, machinebenutting en OEE, machineconditie, materiaalvariatie en afwijkingsdetectie.
- Vertrek van je beschikbare gegevens. In [Modellen per meetopstelling](bronnen.html) vergelijk je wat je kunt afleiden uit een sensorbox met trillings- en fasestroommetingen, CNC-machinedata, operatorinvoer en combinaties daarvan. Open een cel om te zien welke invoer het model nodig heeft.

Toets berekende of geschatte uitkomsten aan metingen op je eigen machine voordat je er procesbeslissingen op baseert.

## Onderhoud

- [gids.css](gids.css) bevat de gedeelde opmaak.
- [gids.js](gids.js) bevat de rekenfuncties voor ruwheid en energie.
- [proeven.js](proeven.js) bevat de interactieve praktijkproeven op de overige modelpagina’s.

Controleer bij wijzigingen aan een modelpagina ook de bijbehorende rij in de meetopstellingenmatrix. Open de gewijzigde pagina in de browser en controleer de links en de rekenvoorbeelden die je hebt aangepast.
